# 유저 등록 및 로그인 기능

### 사용 기술

- C#
- MySql
- SqlKata
- ASP.NET
- Unity 6.3

---

## 구현 목표

- ASP를 활용하여 웹서버 게임을 제작하기 위한 바탕으로 서버와 데이터베이스의 연동과 Unity에서 Http를 통해 서버와의 통신을 하기 위한 최소한의 구조를 제작.
- http 프로토콜의 통신 과정의 이해.

---

## 구현 과정

### Server

서버는 localhost로 진행하며 LoginController와 RegistController를 제작하여 각각 로그인 시도와 유저 등록을 시도함.

### Unity

유니티에서는 Canvas에 로그인 폼을 제작하고, UnityWebRequest를 사용하여 서버와 http 통신을 시도.
